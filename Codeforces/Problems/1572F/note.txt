Define f[i] = Number of station that can broadcast to ith station;

Obviously, this is maintainable with a Segtree. Problem is, later updates can "override"
older updates. Say, we have query "1 1 5" and then query "1 3 5", then the first query
effectively becomes "1 1 2". So, what can we do about this?

Observe that if we have an update on the ith tower, then all previous updates for tower 1 -> i-1
must only affect towers with index < i ie. min(x,i-1) with x is the right bound of that update.

THATS RIGHT, WE ARE DOING SEGMENT TREE BEATS ON UPDATES BABY!!!
